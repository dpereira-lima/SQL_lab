## Explicação em Português

Os scripts deste diretório contêm consultas em SQL Oracle.

O script **old** realiza a consulta dos dados da base utilizando funções de linha simples e funções de grupo, aninhadas.

O script **new** utiliza a mesma lógica do script **old**, porém incorpora as cláusulas **WITH** e **UNION ALL** para apresentar os mesmos dados em um formato equivalente ao **UNPIVOT**, facilitando a transformação das colunas em linhas e tornando o resultado mais adequado para análises e integrações.



## Explanation in English

The scripts in this directory contain Oracle SQL queries.

The **old** script queries the database data using single row functions and nested group functions.

The **new** script uses the same logic as the **old** script, but incorporates the **WITH** and **UNION ALL** clauses to present the same data in a format equivalent to **UNPIVOT**, facilitating the transformation of columns into rows and making the result more suitable for analysis and integration.
